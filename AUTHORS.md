# Authors and Maintainers

Duet is an independent, one-person open-source firmware project for the Xteink X3 and X4. It is built on CrossInk and CrossPoint Reader and includes carefully credited work from several community forks.

## Project Lead

**Lauren Landau** is Duet's creator, project lead, and sole maintainer. Her work includes the product direction, feature design, interface decisions, physical-device testing, release curation, documentation, and original implementation listed in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Development has included coding assistance from OpenAI Codex and Anthropic Claude under Lauren's direction and review. Those tools assist the work; they do not constitute a development team or replace Lauren's authorship and maintainership.

## Contributors

Git history and merged pull requests are the source of truth for individual contributions. Contributions are accepted under the project's MIT License unless a file states a different compatible license.

Authorship of Duet does not replace or diminish upstream authorship. Forks are welcome; preserving accurate credit is part of participating in this project in good faith.
