# WordNet 3.0 dictionary source

The optional `Duet-WordNet-3.0-StarDict.zip` release asset contains an uncompressed StarDict 2.4.2 conversion of the official WordNet 3.0 database.

- Project: https://wordnet.princeton.edu/
- Original release: https://wordnetcode.princeton.edu/3.0/WordNet-3.0.tar.gz
- Original release year: 2006
- Converted book name: `Princeton WordNet 3.0`
- Duet card path: `/dictionaries/English/`
- License: `LICENSE.txt` in this directory and `WORDNET-LICENSE.txt` in the release asset
