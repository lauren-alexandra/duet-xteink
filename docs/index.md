# Duet

Duet is open-source, reading-first firmware for the Xteink X3 and X4. It adds two-device sync, deep reading analytics, configurable dashboards, cover libraries, smart search, custom fonts, and dictionaries while preserving the fast CrossPoint/CrossInk reader foundation.

Duet is created and maintained by Lauren Landau as an independent, one-person project, with upstream work credited throughout the documentation.

[View the official Duet repository](https://github.com/lauren-alexandra/duet-xteink)
