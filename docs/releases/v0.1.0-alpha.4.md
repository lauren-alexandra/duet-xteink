# Duet v0.1.0-alpha.4

Draft public alpha candidate for Xteink X3 and X4.

## Downloads

- Xteink X3: `Duet-X3-v0.1.0-alpha.4.bin`
- Xteink X4: `Duet-X4-v0.1.0-alpha.4.bin`

Use only the file for the matching device. Back up the complete SD card and keep a known-good rollback BIN before installing.

## Complete Reading-Stats Archives

Alpha.4 repairs the complete `.cstats` export and restore path after durable statistics moved to `/.crossink`.

- Global totals, journal and ledger history, session history, Stats Date, library statistics, synced-device statistics, and synced device names are collected from `/.crossink`.
- Per-book `stats*.bin` files remain collected from each book cache under `/.crosspoint`.
- Older archives whose root statistics used legacy `/.crosspoint` paths are restored into the current `/.crossink` locations.
- Restore still validates archive structure and per-entry CRCs, creates a fresh safety export, stages every replacement, and rolls back live files if commit fails.

Full X3 and X4 simulator smoke tests passed a non-empty content-level round trip across global, date, session, synced, and per-book data. Physical X3/X4 export and restore verification is still required before publication.

## Carried Forward

Alpha.4 also contains alpha.3's device/version-gated X4 post-install cleanup, single install-time panel scrub, and quieter ordinary sleep/wake path. X3 sleep and wake waveforms remain unchanged.

The original [Alpha.4 Device Acceptance](https://github.com/lauren-alexandra/duet-xteink/blob/v0.1.0-alpha.4/docs/ALPHA4_ACCEPTANCE_QUICKSTART.md) checklist remains preserved with that historical release. Current testers should use the latest acceptance route.

## Alpha Boundaries

This is not a stable release. Back up first, verify checksums, keep recovery instructions nearby, and report the exact device, version, steps, timing, and smallest privacy-reviewed log needed to reproduce a problem.
