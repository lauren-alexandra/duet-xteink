## Compatibility Mapping

| Legacy source | Canonical destination or behavior |
| --- | --- |
| `/.crossink` | Bounded global state imports to `/.duet/state`; thumbnails import to `/.duet/cache/thumbs`; untouched files remain readable as fallback |
| `/.crosspoint` | Bounded global state imports to `/.duet/state`; durable per-book state migrates lazily to `/.duet/books`; untouched files remain readable as fallback |
| `/.crossink-stats-backup` | Remains a fallback source for reading-stat backups under `/.duet/backups/reading-stats` |

New Duet writes target only `/.duet`. Existing canonical files win over legacy
copies. The migration uses temporary files, flush and size verification, and
atomic rename; it is safe to retry and never deletes a legacy directory.
