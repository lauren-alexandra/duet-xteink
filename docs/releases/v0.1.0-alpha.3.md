# Duet v0.1.0-alpha.3

This matched X3/X4 alpha repairs the X4 cleanup that should run once after a new firmware version is installed.

## Firmware

- Xteink X3: `Duet-X3-v0.1.0-alpha.3.bin`
- Xteink X4: `Duet-X4-v0.1.0-alpha.3.bin`

## Changes Since Alpha 2

- Records the installed device and Duet version in `/.crossink/installed_firmware.txt`.
- Detects the first boot of a new firmware version from that marker instead of relying on the hardware `AfterFlash` wake route. SD-card updates use a software restart that the hardware layer reports as `Other`.
- Runs the X4 post-install black/white cleanup only on that first version boot.
- Removes the updater's redundant pre-restart panel scrub.
- Keeps ordinary X4 sleep/wake on alpha.2's reduced-refresh path.
- Leaves the established X3 boot and sleep waveform behavior unchanged.
- Retains alpha.2's grid-page and carousel lookahead work.

## Physical Test Focus

1. Install alpha.3 on X4 through **SD Firmware Update**. After the one-time first boot finishes, confirm the updater screen is not visible behind Home.
2. Sleep and wake the X4 again. Confirm the one-time install cleanup does not repeat during ordinary cycles.
3. Repeat book-open, Home, sleep, and wake transitions and photograph any settled residue after the panel has stopped updating.
4. Confirm X3 behavior remains the previously accepted sequence.

Build and simulator success do not constitute physical acceptance. Keep the previous known-good BIN until both devices pass these checks.

Alpha.2 was not physically tested: the X4 photo initially attributed to it was later confirmed to have been taken while the older `alpha.1-lookahead1.ghost1` build was still installed.

## Publication Gate

This remains a draft candidate. Complete `.cstats` export and restore must be repaired and verified after root statistics moved to `/.crossink`; the current collector still scans the legacy `/.crosspoint` tree and can produce an empty export. Do not publish or rely on the complete archive feature until both device builds pass a non-empty export-and-restore round trip.
