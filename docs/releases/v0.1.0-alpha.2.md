# Duet v0.1.0-alpha.2

This matched X3/X4 alpha focuses on physical-reader responsiveness and a quieter, more predictable sleep/wake sequence.

## Firmware

- Xteink X3: `Duet-X3-v0.1.0-alpha.2.bin`
- Xteink X4: `Duet-X4-v0.1.0-alpha.2.bin`

## Changes Since Alpha 1

- Restores the visible **Going to sleep** confirmation on both readers.
- Removes the X4 sleep-entry controller scrub that added a long inversion sequence without improving the settled sleep image.
- Prevents ordinary X4 deep-sleep wake from running the black/white post-firmware scrub. X4 wake now paints the Duet splash once instead of running three full refreshes.
- Keeps the established X3 sleep and boot presentation unchanged.
- Keeps the current grid page plus memory-safe previous/next page cover lookahead, so ordinary page changes can reuse already hydrated artwork.
- Keeps the carousel's five visible covers plus one hidden lookahead cover in each direction.

## Physical Test Focus

1. On X4, sleep from Home and from an open book. Confirm **Going to sleep** appears, the chosen sleep image settles cleanly, and the old screen is not visible afterward.
2. Wake the X4 and confirm the Duet splash uses one panel refresh rather than the prior repeated black/white cycle.
3. Repeat the same test on X3 and confirm its previously accepted behavior is unchanged.
4. In 2x2, 3x3, and 4x4 grids, move forward and backward across several page boundaries and confirm the cursor remains responsive while adjacent covers hydrate.

Build and simulator success do not constitute physical acceptance. Keep the previous known-good BIN until both devices pass these checks.
