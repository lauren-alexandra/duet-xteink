# Font License Index

`FONT_PACK_SOURCES.tsv` is the family-by-family index for this archive. Each row names the generated family, its upstream project, the pinned source revision or package reference, and the applicable license note.

## Google Fonts

The `google-fonts/` folder contains the family-specific copyright and license notice copied from the pinned Google Fonts revision. Most families use SIL Open Font License 1.1; Roboto Slab, Special Elite, and Yellowtail use Apache 2.0; Ubuntu uses the Ubuntu Font License 1.0. Tinos is distributed from Google Fonts' `ofl/tinos` directory without a separate `OFL.txt` in that revision, so this archive includes its pinned `METADATA.pb` record together with `SIL-OFL-1.1.txt`.

## Nico Verbruggen E-Reader Fonts

`ebook-fonts-pinned-README.md` is copied from the exact `nicoverbruggen/ebook-fonts` revision listed in `FONT_PACK_SOURCES.tsv`. It records the original project and modification history for each included e-reader derivative. Most use SIL Open Font License 1.1. NV Charter uses the included Bitstream Charter notice. NV Adelph uses the Open Inclusive Font License text preserved in `Open-Inclusive-Font-License-source.html`.

## CrossInk Fonts

`crossink-fonts/` contains the font notices shipped by the pinned `uxjulia/crossink-fonts` source revision.

## CTAN And Other Open Projects

The CTAN families map to their exact package links in `FONT_SOURCES.md`. SIL Open Font License 1.1 covers Cochineal and KpRoman. The GUST Font License covers Antykwa Torunska and the TeX Gyre families. `ETbb-README.txt` preserves ETbb's project notice and MIT license statement. Coelacanth and SIL Gentium use SIL Open Font License 1.1.

This index records the sources and notices bundled with the generated Duet assets. It is not legal advice.
